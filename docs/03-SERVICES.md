# Aakrin — Services

Aakrin provides the full Salesforce service lifecycle.

## Core service categories

- Salesforce Consulting
- Salesforce Implementation
- Salesforce Customization
- Salesforce Development
- Salesforce Integration
- Data Migration
- Salesforce Optimization
- Salesforce Support & Maintenance
- Lightning Migration
- AppExchange-related development/services
- Agentforce / AI
- Data Cloud-related services

The exact commercial packaging can be refined later.

## Service architecture

Services answer:

> What can Aakrin do for me?

Do not make visitors infer the service catalogue solely from problem statements.

The homepage should have an explicit service section.

Problem-based navigation can still be used as a secondary UX layer.

## Recommended lifecycle presentation

Discover
→ Plan
→ Implement
→ Integrate
→ Customize
→ Automate / AI
→ Optimize
→ Support

This should visually communicate end-to-end capability.

## Agentforce

Agentforce is a first-class Aakrin capability.

Do not bury it in a generic AI paragraph.

Potential capability themes:

- Agentforce implementation
- Agentforce customization
- AI agents
- AI automation
- Data Cloud + Agentforce
- Salesforce AI engineering

Exact wording must not claim capabilities that Aakrin cannot actually deliver.
