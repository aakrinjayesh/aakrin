# Aakrin — Design System Direction

## Brand personality

The visual design should feel:

- AI-forward
- Salesforce-specialist
- Startup-like
- Technical
- Premium without feeling corporate-heavy

## Design principle

The site should look like a modern engineering company building on Salesforce, not like a generic IT services outsourcing website.

## Visual hierarchy

Prioritize:

1. Strong typography
2. Clear hierarchy
3. High-quality whitespace
4. Strong but controlled visual contrast
5. Subtle technical/AI visual language
6. Product-like cards
7. Motion used for meaning, not decoration

## Avoid

- Excessive gradients
- Generic corporate stock photos
- Giant walls of text
- Excessive rounded cards with no hierarchy
- Every section looking identical
- Too many competing CTAs
- Overly flashy AI visuals
- Fake dashboards that do not communicate anything
- Excessive animations that harm performance

## Component principles

Cards should have clear hierarchy:

Title
→ short explanation
→ relevant capability
→ action/link

Do not make every card clickable if it does not need to be.

## CTA hierarchy

Primary:
Book a Salesforce Consultation

Secondary:
Tell us what you need

Contextual links:
Explore services
View case studies
See Salesforce expertise

Avoid creating a different CTA label for every card unless there is a real contextual reason.

## Responsive design

Design mobile intentionally.

Do not simply stack desktop sections.

Mobile priorities:

1. Positioning
2. Primary CTA
3. Proof
4. Services
5. Expertise
6. Results
7. Quiz / enquiry
8. Footer

## Accessibility

Target:

- semantic HTML
- keyboard navigation
- visible focus states
- sufficient contrast
- reduced-motion support
- accessible form labels
- descriptive buttons/links
- meaningful heading hierarchy
