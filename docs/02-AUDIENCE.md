# Aakrin — Audience

## Primary commercial audiences

1. Salesforce consulting partners
2. Startups
3. SMBs
4. Mid-market companies

Target company size:
- 100+ employees

Geography:
- Global

## Buyer / stakeholder roles

- Founder / CEO
- CTO
- CIO
- COO
- Head of Sales
- Head of Operations
- Salesforce Admin

## What the visitor should recognize quickly

Within the first screen, a visitor should be able to understand:

1. Aakrin is Salesforce-specialized.
2. Aakrin provides engineering capability, not just high-level advice.
3. Aakrin can work across multiple Salesforce clouds/platforms.
4. Aakrin can support both consulting partners and businesses.
5. There is a clear next step.

## Audience split

The homepage should provide a clear route for:

### Salesforce consulting partners

Messaging themes:
- Extend your delivery team
- Add specialist engineering capability
- Handle complex Salesforce work
- Add Agentforce / Data / integration expertise
- Scale delivery without permanent hiring

### Businesses

Messaging themes:
- Implement Salesforce
- Fix or improve an existing Salesforce org
- Integrate systems
- Migrate data
- Customize and automate
- Add AI/Agentforce
- Get ongoing support

Do not create two completely separate websites. Use clear paths within one coherent architecture.
